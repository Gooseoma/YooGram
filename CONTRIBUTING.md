## Какие изменения принимаются

Мы высоко ценим ваш вклад в виде исправления ошибок и оптимизации исходного кода Telegram Desktop и его документации. Если вы исправляете существующее поведение, отправьте изменения в свой форк и [создайте pull request][pr].

Подождите нашего ответа. Мы стараемся рассматривать pull request'ы как можно быстрее.
Если мы найдём проблемы в вашем pull request, мы можем предложить изменения и улучшения.

К сожалению, мы **не принимаем** pull request'ы, которые добавляют новые функции, переводы на новые языки или вводят любые новые элементы пользовательского интерфейса.

YooGram не является Telegram, это всего лишь форк (мод) на него.

## Как добиться принятия вашего pull request

Мы хотим улучшать YooGram с помощью вашего вклада. Но мы также хотим обеспечить стабильную работу для наших пользователей и сообщества. Следуйте этим правилам, и всё получится без проблем!

### Один pull request: одна проблема

Pull request'ы должны быть как можно меньше и атомарнее. Большие изменения, затрагивающие много всего, будут **отклонены** с просьбой выделить конкретный код в вашем pull request. Примеры:

* Если вы исправляете опечатки в документации, не меняйте другие файлы.
* Если вы добавляете новые функции, не «наводите порядок» в несвязанных функциях. Такая чистка должна быть в отдельном pull request.


#### Объединяйте коммиты в один

Чтобы история проекта оставалась чистой, делайте один коммит на один pull request.
Если у вас уже несколько коммитов, их можно объединить (squash) следующими командами в Git Bash:

1. Откройте `Git Bash` (или `Git Shell`)
2. Введите команду, чтобы объединить последние {N} коммитов: `git reset --soft HEAD~{N} && git commit` (замените `{N}` на число коммитов, которые хотите объединить)
3. Нажмите <kbd>i</kbd>, чтобы перейти в режим вставки
4. Введите сообщение нового коммита
5. После ввода сообщения нажмите <kbd>ESC</kbd>, чтобы выйти из режима вставки
6. Напишите `:wq` и нажмите <kbd>Enter</kbd>, чтобы сохранить новое сообщение, или `:q!`, чтобы отменить изменения
7. Введите `git push --force`, чтобы отправить новый коммит в удалённый репозиторий

Например, чтобы объединить последние 5 коммитов, используйте `git reset --soft HEAD~5 && git commit`

### Не смешивайте изменения кода с чисткой пробелов

Если вы меняете две строки кода и исправляете 200 строк с пробелами в файле, то дифф такого pull request'а становится практически нечитаемым, и он будет **отклонён**. Чистка пробелов должна быть в отдельном pull request.

### Тестируйте свои изменения!

Перед отправкой pull request'а протестируйте свои изменения. Убедитесь, что Yoogram по-прежнему работает и ваши изменения не вызывают других проблем или падений.
Для этого используйте Android Studio для сборки APK

### Пишите хорошие сообщения коммитов

* Объясняйте, зачем вы вносите изменения. [Подробнее о хороших сообщениях коммитов.][commit_message]

* Если коммит исправляет issue, закройте его, [добавив одно из ключевых слов и номер issue][closing-issues-via-commit-messages] в сообщение коммита.

  Например: `Fix #545`
