# YooGram - неофициальный форк (мод) на телеграмм


Неофициальный форк (мод) на телеграмм
В данном репозитории будет именно Android-Mobile версия (на телефоны)

---------

# Основные фишки YooGram

#№ Красивый стиль

В YooGram убраны ограничения на использование "жидкого стекла" (Работает на android 13 и выше)
Полностью настраивается внешний вид цветов

# Удобство для администраторов телеграмм каналов/чатов

## Для редакторов каналов:
Быстрое закрепление поста, автоматическое добавление ватермарки (Пишется "Подпишись на канал" как кликабельная ссылка, текст можно сменить в настройках YooGram)

## Для администраторов групп

Быстрая выдача наказания - нажал на сообщение - сразу по нему можешь выдать наказание
