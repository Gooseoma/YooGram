# Кастомный прокси лист (добавление в стандартный) список прокси серверов

В чем суть нововведения?
Будут добавлены по умолчанию прокси сервера которым мы доверяем (свои и сторонние)

Как реализовать:
Сразу уже есть в корнях проекта файл с прокси серверами, если же его нет создать аналог его, и чтоб он из сервера для подгрузки бейджиков грузил еще и список прокси
